# Voruganti Lokesh — Portfolio

This is my personal developer portfolio built with React, Vite and Tailwind CSS.

Live Website:
https://vorugantilokesh.vercel.app

## Tech Stack
React
Vite
TypeScript
Tailwind CSS
shadcn/ui

## Features
- Responsive design
- Dark/Light theme
- Projects showcase
- Coding profiles
- Resume download
- Contact links

## Run Locally
git clone https://github.com/Lokesh-up/lokesh-portfolio-splash.git
cd lokesh-portfolio-splash
npm install
npm run dev
